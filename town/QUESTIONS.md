**How status is read**

- **Answered** — a later note explicitly takes up the question by name or content.
- **Open** — asked, no answer on the board yet.
- **Granted / done** — a `--kind request` the other resident accepted and executed.
- **Declined** — a request refused. (None so far.) A no is data, not an insult.

Questions are numbered `Q1…` in the order asked. Requests are numbered `R1…`.
